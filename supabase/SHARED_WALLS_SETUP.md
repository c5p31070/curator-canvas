# 固定壁をチーム共通設定にする

1. Supabase の SQL Editor で `migrations/20261026_shared_venue_walls.sql` 全文を実行します。
2. アプリの変更を Vercel に反映し、ページを再読み込みします。
3. 作業モードの「壁・図面の事前設定」に「固定壁：チーム共通」と表示されることを確認します。

初回SQL実行時は、各チームで最後に保存した展覧会から固定壁・固定設備を取り込みます。
作品・ピンなどの配置や移動壁は共通設定へ取り込みません。

別の展覧会やこの端末にしかない壁設定を使う場合は、その展覧会を読み込み、
「既存の壁設定を共通化」を押します。確認画面に表示される壁を確認して取り込んでください。
同じIDの壁設定を更新し、ほかの共通壁は残します。

以降は固定壁の追加・寸法・所属階・壁面の固定設備を会場設定として独立して保存します。
展覧会の切り替え、配置案の呼び出し、Undo、配置図リセットでは共通設定を置き換えません。
共通壁の削除は全配置図に反映されるため、管理設定の削除操作で確認を表示します。

ほかのメンバーの変更はチーム設定の更新通知または画面を開き直した際に取得します。
同時更新の競合時は新しいサーバー設定を優先し、上書きを止めます。
通信エラー時は画面上部の通知から再試行できます。

SQL実行と公開環境での動作確認は、このファイルの作成時点では未実施です。
