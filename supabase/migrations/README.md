# 平面図の縮尺をチーム共通にする

1. Supabaseの対象プロジェクトで **SQL Editor → New query** を開きます。
2. `20261020_shared_floor_scale.sql` の内容をすべて貼り付けて実行します。
3. 変更したアプリをVercelに反映し、開いているアプリを再読み込みします。

既存チームは、最新の保存済み展覧会に記録された有効な縮尺を引き継ぎます。
記録がないチームは `0.5 px/cm` で開始します。必要に応じて作業モードで設定してください。
一度設定すると、展覧会や配置案を切り替えても、端末を変えても、チーム共通値が使われます。

管理者・編集者は作業モードで縮尺を変更できます。閲覧者は変更できません。
変更は他の端末にも通知され、アプリに戻ったとき・展覧会の保存や読み込み・PDF出力の前にも取得します。
展覧会に保存されていた古い縮尺や、その端末だけの縮尺で共通設定を上書きしません。

通信やSQLの設定に問題がある場合は案内を表示して編集を停止します。
解消後は案内の「再読み込み」を押してください。

既存環境では、この追加SQLだけを実行してください。`schema.sql` 末尾の管理者作成処理を再実行する必要はありません。

## 公募展会場の追加

既存の共有縮尺・共通壁の設定に加えて、Supabase SQL Editorで
`20261111_public_exhibition_scale.sql` を一度実行し、アプリを公開し直します。
企画展の縮尺は既存の値を保持し、公募展の縮尺は未設定から始まります。

アプリで「保存 → 新規展覧会」を開き、展覧会名と公募展会場を選びます。
管理者モードで、図面上の既知の距離を使って公募展の縮尺を設定してください。
公募展の固定壁・固定設備は、公募展会場を開いた状態で登録します。
登録した固定壁は、同じチームの他の公募展でも使用できます。
