# 発表用ゲスト体験

ログイン画面の「ゲストで試す」、または `editor.html?guest=1` から入ります。
アカウント作成、匿名認証、パスワード入力はありません。

## 操作・データ

- 展示物・ピン・描画・移動壁・編集・混雑表示・保存・PDF出力を利用できます。
- 管理者モード、チーム共有は表示しません。
- 配布されたレール上でスポットライトの追加・移動・照射先指定・点灯切替・削除を体験できます。
- レール・固定ライトの設置位置は変更できません。固定ライトの点灯切替は可能です。
- 各階に用意した体験用壁面を使います。縮尺は配布データの値を使い、未配布時のみ0.5 px/cmです。
- 作品配置はブラウザー内の `curator_canvas_guest_demo_v1:` 専用保存領域に保存します。
- 通常アカウントの下書き・共通設定・保存済み展覧会は読み書きしません。
- ゲスト終了時も、通常アカウントの認証セッションは変更しません。

ゲストのエディタではSupabaseクライアントを作成しません。
認証、データベース、チーム設定取得、共有保存、Realtimeへのリクエストは発生しません。
HTML・JavaScript・図面画像のVercel配信や、外部CDNへの通信は発生します。

## 管理者の照明配置をゲストに配布する

1. レールを設定したブラウザーで通常ログインし、管理者モードを開きます。
2. 「ゲスト用照明データを書き出す」を押します。
3. ダウンロードされた `guest-venue-preset.js` で、プロジェクトの `js/guest-venue-preset.js` を置き換えます。
4. コミット・プッシュしてVercelに反映します。ゲストはページを再読み込みしてください。

全階のレール・固定ライト・共通縮尺だけを静的ファイルとして公開します。
展覧会、作品、注意書き、スポットライト、アカウント情報は書き出しません。
初期ファイルは未配布の空データです。実際の配置は管理者のブラウザー内にあるため、上の書き出し操作が必要です。
更新のたびに書き出し・置き換え・公開を行います。同じ配布版ではゲストの操作状態を維持します。
配布版が変わると会場照明と縮尺を更新し、削除されたレール上のスポットライトは読み込み時に除去します。
ゲスト自身の作品配置や保存済み展覧会は消去しません。

## 後から無効化する

`js/guest-demo.js` 冒頭の `const enabled = true` を `false` に変更して公開します。
ログイン画面から入口が消え、`?guest=1` で開いても通常のログイン認証が必要になります。

完全に外す場合は、`login.html` の `guestDemoEntry` と、
`login.html` / `editor.html` の `js/guest-demo.js` 読み込み、`editor.html` の
`js/guest-venue-preset.js`・`js/editor/guest-lighting-export.js` 読み込みと配布ボタンを削除し、
これらのゲスト専用ファイルと `css/guest-demo.css` を削除できます。
ほかのコードはゲスト機能の存在を任意として扱い、通常の認証・保存へ戻ります。
専用保存領域は通常アカウント用の保存領域に転用しません。

公開にはアプリの変更をVercelに反映してください。追加のSupabase SQLは不要です。
実画面での動作確認は、この文書の作成時点では未実施です。
